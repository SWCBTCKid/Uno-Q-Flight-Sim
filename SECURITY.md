# Security policy

This is alpha software that launches a native direct-KMS application with a
root-controlled restore envelope. Review scripts before granting `sudo`.

Do not report credentials or sensitive machine data in a public issue. Use
GitHub's private vulnerability-reporting channel when it is enabled for the
repository. Never attach flight logs without reviewing them for usernames,
paths, device identifiers and local network information.

Supported security updates currently apply only to the latest alpha tag.
